#  JSON Array + Tailwind Display Activity

##  Objective
Use JavaScript to iterate through a JSON-style array and display each item as a styled card using Tailwind CSS.

##  Files
- `index.html`: Basic structure with Tailwind CDN and a placeholder for product cards.
- `script.js`: Contains an example array and steps to complete the assignment.

---

##  Tasks

1. Add one or more new products to the `products` array.
2. Add a new property called `category` to each product and display it on the page.
3. Inside each card, add a styled button that says **"Add to Cart"**.
4. Use Tailwind utility classes to style your cards and buttons (`bg-white`, `rounded`, `shadow`, `hover:*`).
5. Make sure the layout adjusts responsively using Tailwind's grid system (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
